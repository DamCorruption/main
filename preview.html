Attributes & Vector Calculations

System reference sheet mapping calculation logic, variables, and game object usage contexts.

⚡ Interactive Matrix Filter:
tgxs Positioning
To Goal X (Same Team)
Measures the horizontal distance between the target item and its own team's goal line.
xI = item.x - centerX;
goalX = me.team === 2 ? red : blue;
result = xI - goalX;
Targets: ball self other
tgxo Positioning
To Goal X (Opponent Team)
Measures the horizontal distance between the target item and the opposing team's goal line.
xI = item.x - centerX;
goalX = me.team === 3 ? red : blue;
result = xI - goalX;
Targets: ball self other
tgyt Positioning
To Goal Y (Top Post)
Measures vertical tracking distance between the item and the upper goalpost crosshair line.
yI = item.y - centerY;
result = yI - goalYTop;
Targets: ball self other
tgyb Positioning
To Goal Y (Bottom Post)
Measures vertical tracking distance between the item and the lower goalpost boundary limits.
yI = item.y - centerY;
result = yI - goalYBottom;
Targets: ball self other
tbx Relative Position
Distance to Ball X
Calculates the relative horizontal spacing delta scalar layout between the entity and the ball.
xI = item.x - centerX;
ballx = ball.x - centerX;
result = xI - ballx;
Targets: self other
tby Relative Position
Distance to Ball Y
Calculates vertical distance separating an active system runner element or opponent away from ball.
yI = item.y - centerY;
bally = ball.y - centerY;
result = yI - bally;
Targets: self other
rvxm / rvym Normalized Velocity
My Relative Velocity Vector
Computes normalized unit heading vectors of your player relative to current Ball speed momentum values.
relX = item.xv - ball.xv;
speed = Math.hypot(relX, relY);
return speed === 0 ? 0 : relX / speed;
Targets: self
rvxb / rvyb Normalized Velocity
Ball Relative Velocity Vector
Yields directional unit velocity vectors mapping exactly how the ball accelerates or tracks against you.
relX = item.xv - me.xv;
speed = Math.hypot(relX, relY);
return speed === 0 ? 0 : relX / speed;
Targets: ball
rvxi / rvyi Normalized Velocity
Intercept Tracking Velocity
Measures normalized heading velocity adjustments against the midpoint average speed vectors of Me + Ball.
refX = (me.xv + ball.xv) / 2;
relX = item.xv - refX;
speed = Math.hypot(relX, relY);
return speed === 0 ? 0 : relX / speed;
Targets: other
